# 🖼️ Photo Editing Web App

A powerful photo editing platform that allows users to erase backgrounds, change scenes, and apply other image transformations. Built with modern web technologies and ready for scalable deployment.

---

## ✨ Features

- ✂️ Background removal
- 🎨 Image transformation and editing
- ☁️ Cloud-based image storage (Cloudinary)
- 💳 Stripe-powered secure payments
- 🧩 Beautiful UI with `shadcn/ui`
- 🧠 Optimized performance with Next.js
- 🗃️ MongoDB for data persistence

---

## 🛠️ Tech Stack

- **Frontend:** Next.js, Tailwind CSS, `shadcn/ui`
- **Backend:** Next.js API routes
- **Database:** MongoDB
- **Cloud Storage:** Cloudinary
- **Payments:** Stripe
